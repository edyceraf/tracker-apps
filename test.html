🔗 API Endpoints:

POST /api/track-visitor - Track visitor location
GET /api/visitors - Get all visitors
GET /api/stats - Get statistics
DELETE /api/visitors/:id - Delete specific visitor
DELETE /api/visitors - Clear all data
